# music-analyzer-site-2

이 프로젝트는 음악 파일을 업로드하면 오디오 정보를 분석하고 시각화하는 웹 사이트입니다.

## 사용 방법

1. `index.html` 파일을 브라우저에서 열거나 간단한 로컬 서버에서 실행하세요.
2. 음악 파일(MP3, WAV, AAC 등)을 업로드하거나 드래그 앤 드롭합니다.
3. 곡의 메타데이터, 파형, 주파수 스펙트럼, BPM, 음압, 주요 음색 등이 자동으로 분석되어 표시됩니다.

## 실행 방법

로컬 서버를 사용하려면 폴더에서 다음 명령을 실행하세요:

```bash
python -m http.server 8000
```

그런 다음 브라우저에서 `http://localhost:8000`을 엽니다.
